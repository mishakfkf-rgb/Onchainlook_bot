# Onchain Bot

Telegram-бот для ончейн-мониторинга токенов и кошельков с алертами в реальном времени на Python + SQlite

# Что умеет

- Отслеживать крупные переводы токенов между ончейн-кошельками и CEX (и в ту и в другую сторону, в самом боте помечается красным и зеленым кружком)
- Поддерживает несколько сетей: Ethereum, BSC, Polygon, Arbitrum (пока что как я тестил ETH сеть самая стабильная и без ошибок)
- Отправлять алерты по порогу в USDT (например от `$5,000` или от `$1,000,000`)
- Отслеживать активность конкретного кошелька в выбранной сети
- Сохранять настройки и курсоры в SQLite, чтобы не терять состояние после перезапуска бота

# Команды бота

- /start — старт и гайд по боту
- /help — как пользоваться
- /add — добавить токен в трекинг
- /list — список токенов которые вы трекаете
- /remove — удалить токен из трекинга
- /addwallet — добавить отслеживание кошелька
- /wallets — список отслеживаемых кошельков
- /removewallet — удалить кошелек из трекинга
